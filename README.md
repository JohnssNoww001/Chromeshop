# Chromeshop

A free mod manager for Cyberpunk 2077. Drag and drop mod archives (.zip, .7z, .rar), see exactly where every file goes, install in one click, and remove or disable mods safely without touching game files.

## Features
- Drag and drop installs, with a preview of every install folder
- Installs many mods at once
- One-click download of the core mods (RED4ext, redscript, Cyber Engine Tweaks, Codeware, ArchiveXL, TweakXL)
- Warns before one mod overwrites another's files
- Enable, disable and remove mods without touching game files
- Customizable theme

## Install
Download **Chromeshop_x.x.x_x64-setup.exe** from the Releases page on the right and run it.
Windows may show a blue "protected your PC" screen because the app isn't code-signed yet: click **More info**, then **Run anyway**.

Windows only. Not affiliated with CD PROJEKT RED or Nexus Mods.
