## ✨ What it does

- 📦 **Drag and drop installs.** Drop many `.zip`, `.7z` and `.rar` mod files at once. Chromeshop works out where each file goes.
- 🧠 **Smart warnings.** Tells you when a mod needs another mod, or would replace files you already have.
- 🔁 **Updates replace old versions** automatically, so you never get duplicates.
- 🔀 **Load order.** Drag archives up and down, or use the arrow buttons.
- 🩺 **Health page.** Reads the game's script errors and crash reports, points to the mod that caused them, and can find a broken mod for you step by step.
- 🧱 **Core mods made easy.** Installs and updates RED4ext, redscript, Cyber Engine Tweaks, Codeware, ArchiveXL and TweakXL, using versions that match your game.
- 💾 **Backups.** Back up your save games and your mod settings, with one-click restore.
- ↩️ **Undo.** Undo your last install, or start fresh with Deep clean.
- 📸 **Screenshot hotkey** with a soft sound, plus a gallery for your shots.
- 🎨 **Your look.** Colours, fonts and themes you can change.

## 📥 Install

1. Go to the [**Releases**](../../releases/latest) page and download `Chromeshop_x.x.x_x64-setup.exe`.
2. Run it and follow the installer.
3. Open Chromeshop. On the **Setup** page, press **Auto-detect** (or **Choose folder**) to find your game.
4. Press **Install missing** to add the core mods most other mods need.
5. Drag your mod files into the **Home** page and press **Install**.

**Needs:** Windows 10 or 11, and Cyberpunk 2077 (Steam, GOG or Epic). For `.rar` files, having 7-Zip or WinRAR installed works best.

## 🛡️ Windows says "Windows protected your PC"?

That's Windows SmartScreen. It shows this for any new app that isn't signed with a paid certificate. Chromeshop is free and doesn't have one yet.

1. Click **More info**.
2. Click **Run anyway**.

You only need to do this once per version. Updates made inside the app check the downloaded file against the fingerprint GitHub recorded for it.

## ⚠️ Good to know

- **Match your game version.** New core mod versions only work on new game versions. For example, RED4ext 1.31 and newer needs game patch 2.5 or newer. If your game is older, Chromeshop installs the last matching versions.
- **Chromeshop only touches what it installed.** Removing a mod deletes only the files it added and puts back any game file it replaced.
- **Close the game** before installing, removing, restoring or reordering.
- **Virtual Atelier** and some other mods can't be downloaded automatically. Download them yourself, then save a copy in Chromeshop (Setup page) for next time.

## ❓ FAQ

**Is it safe?** It only changes files inside your Cyberpunk 2077 folder, keeps a log of everything it installs, and backs up any file it replaces.

**Does it work with Nexus Mods?** You download mods from Nexus yourself and drop the files into Chromeshop. Automatic Nexus downloads are not part of it yet.

**The game shows a script error. What now?** Open the **Health** page. It shows which mod caused the errors and has a **Disable** button next to it.

**Something is badly broken.** Use **My mods → Bulk actions → Deep clean**, verify your game files in your launcher, then install again.
